# SignalHound — Design System

> Дизайн-документ фронтенда. Источник истины для всех UI-решений.
> Живой прототип всех экранов: `signalhound-prototype.html` (открыть в браузере, навигация в сайдбаре кликабельна).

---

## 1. Концепция

**Метафора: спектроанализатор.** SignalHound ловит сигналы в эфире интернета — визуальный язык продукта заимствован из мира радио и измерительных приборов: тёмный экран прибора, янтарное фосфорное свечение, моноширинные показания, шкалы уровня сигнала.

**Характер:** инженерный, точный, спокойный. Интерфейс — рабочий инструмент, не маркетинговый сайт. Ничего не кричит; горячее выделяется само за счёт сдержанности остального.

**Анти-паттерны (запрещено):**
- Фиолетово-розовые «AI-градиенты» (#7C3AED→#EC4899 и родня) — клише AI-продуктов
- Кислотно-зелёный «хакерский терминал» — второе клише
- Эмодзи вместо иконок (только SVG: Lucide/Heroicons)
- Светлая тема как дефолт (продукт мониторинговый, живёт на втором мониторе)
- Градиенты в UI-элементах, глоу-эффекты крупнее 10px, стеклянные карточки

## 2. Токены

### 2.1. Цвет

| Токен | HEX | Роль |
|---|---|---|
| `--bg` | `#0B0E14` | Фон приложения (глубокий чернильный, не чистый чёрный) |
| `--surface` | `#12161F` | Карточки, панели |
| `--surface-2` | `#171C28` | Hover-состояния, приподнятые элементы |
| `--border` | `#232A38` | Активные границы, разделители форм |
| `--border-soft` | `#1B2130` | Тихие границы карточек |
| `--text` | `#E8EAF0` | Основной текст |
| `--text-mut` | `#8B94A6` | Вторичный текст |
| `--text-dim` | `#5C6B84` | Подписи, метаданные, выключенное |
| `--amber` | `#FFB224` | **Сигнальный янтарь.** Акцент бренда: активная навигация, скоры 61–84, кнопки, графики |
| `--amber-soft` | `rgba(255,178,36,.12)` | Фон активных чипов/пунктов |
| `--hot` | `#FF6B4A` | Горячие лиды (score ≥ 85), пиковые значения |
| `--live` | `#3DD68C` | **Только** live-индикаторы, статусы «up/active/customer». Никогда — как декоративный акцент |
| `--danger` | `#E5484D` | Ошибки, критические алерты |

**Правило температуры:** чем выше интент — тем теплее цвет. Шкала скора: `--text-dim` (0–40, притушенные карточки opacity .65) → `--amber` (41–84) → `--hot` (85–100). Это единственная семантика цвета в ленте — не использовать эти цвета для другого.

### 2.2. Типографика

| Роль | Шрифт | Использование |
|---|---|---|
| Display | **Space Grotesk** 700 | Заголовки страниц (h1 20px), логотип, крупные значения-слова |
| UI/Body | **Inter** 400/500/600 | Весь интерфейсный текст, заголовки карточек (600 14px), body 13–14px |
| Data | **JetBrains Mono** 400/500/700 | Скоры, числа, метаданные (11px), лейблы секций (10.5px uppercase, letter-spacing 1px), конфиг, время |

Правило: **любое число в интерфейсе — моно.** Метаданные и лейблы секций — только моно-uppercase 10–11px цветом `--text-dim`.

### 2.3. Геометрия

- Радиус карточек `--r: 10px`; вложенные элементы 6–8px; чипы 999px
- Сетка: сайдбар 216px фикс; детальная панель 380px; контентные гриды gap 10–12px
- Отступы карточек: 14–16px; плотность высокая — это рабочий инструмент
- Брейкпоинты: 1180px (скрыть detail-панель), 820px (скрыть сайдбар → мобильное меню)

### 2.4. Движение

- Переходы: 150ms на hover (border-color, background, color), transform максимум `translateY(-1px)`
- Единственная постоянная анимация — пульс live-точки (2s, box-shadow ripple)
- `prefers-reduced-motion: reduce` → всё отключается (обязательно)

## 3. Сигнатурные элементы

### 3.1. Шкала уровня сигнала (signal meter)
Главный узнаваемый элемент бренда. Скор лида = 5 восходящих штрихов (как индикатор приёма на рации) + число моно-шрифтом под ними.

- Размеры: standard (22px высота, штрих 5px) и small (14px, штрих 3.5px) для строк и канбан-карточек
- Заполнение по уровням: 0–40 → 2 штриха `--text-dim`; 41–60 → 3 amber; 61–84 → 4 amber; 85+ → все 5 `--hot`
- Незаполненные штрихи всегда видимы цветом `--border` (шкала, а не бары)
- Повторяется: логотип (ломаная сигнала с hot-точкой), карточки ленты, детальная панель, канбан, test-scoring

### 3.2. Waterfall-теплокарта (Dashboard)
Сетка 7×24 (день × час), интенсивность = количество сигналов: `--border-soft` → amber 18% → amber 45% → `--amber` → `--hot`. Отсылка к waterfall-дисплею SDR-приёмников. Ячейки 2px gap, radius 2px.

### 3.3. Прозрачность затрат
Расход LLM-бюджета виден всегда: прогресс-бар в футере сайдбара + стоимость каждой операции в UI (test-scoring показывает `cost: $0.0004 · 1.2s`). Философия продукта, зашитая в интерфейс.

### 3.4. Этика в UI
Под каждым черновиком ответа: *"Drafts are never sent automatically. You review, you send."* Кнопка Copy, никогда Send.

## 4. Компоненты

| Компонент | Спецификация |
|---|---|
| **Signal card** (Feed) | Grid `64px 1fr auto`. Слева meter, центр: мета-строка (источник + intent-тег + язык) → заголовок 600 → сниппет 2 строки с `<mark>` цвета amber на ключевой фразе. Hot-карточки: `border-left: 2px solid --hot`. Выбранная: border amber 45%. Score<40: opacity .65 |
| **Intent-теги** | Моно 10px uppercase, фон 12% прозрачности: `pain`→hot, `hiring`→live, `buying/research`→amber |
| **Чипы-фильтры** | Radius 999px, счётчик моно с opacity .75; активный — amber-soft фон + amber текст |
| **Кнопки** | Primary: amber фон + тёмный текст `#0B0E14` (hover `#FFC14E`); Ghost: 1px border. Радиус 8px, 600 13px |
| **Kanban-карточка** (Leads) | Имя 600 13px → контекст моно 11px dim → футер: meter-sm + счётчик сигналов. Статусные border-left: contacted-warm→amber, customer→live |
| **Detail-панель** | Скор 34px mono amber + meter → заголовок → цитата (border-left 2px amber) → «Why this score» списком → черновик (dashed border) → действия внизу |
| **Таблицы** (Stats) | Заголовки — лейбл-стиль (моно uppercase dim); числа моно; первая колонка `--text`, остальные `--text-mut` |
| **Формы** (ICP) | Инпуты на `--bg` с border `--border`, focus → amber 50%. Лейблы над полями — sub-стиль. Тогглы 32×18px, включенный — amber |
| **Test scoring** | Sticky-панель справа: textarea моно → Run test → результат: скор + meter + причины + стоимость/время/модель |
| **Пустые состояния** | Иконка + одна строка что сделать + кнопка действия. Без иллюстраций-масок |

## 5. Голос интерфейса (UX writing)

- Язык UI — английский, sentence case, без восклицаний
- Кнопки называют действие: "Add to leads", "Run test", "Save & reload" — не "Submit"/"OK"
- Числа с контекстом: не "147", а "147 signals · 24h"; не "$0.68", а "$0.68 / $2.00 cap"
- Ошибки: что случилось + как починить, без извинений ("Reddit collector: auth expired → reconnect in Sources")
- Объяснимость скора всегда формулируется как цитата-доказательство: `✓ Explicit intent: "considering bringing in outside help"`

---

## 6. Чеклист качества (перед каждым релизом UI)

- [ ] Иконки — только SVG (Lucide), никаких эмодзи
- [ ] `cursor: pointer` на всём кликабельном
- [ ] Hover-переходы 150–300ms
- [ ] Контраст текста ≥ 4.5:1 (`--text-mut` на `--surface` проходит)
- [ ] Видимые focus-стейты (2px amber outline, offset 2px)
- [ ] `prefers-reduced-motion` уважается
- [ ] Адаптив: 375 / 768 / 1024 / 1440
- [ ] Цветовая семантика не нарушена (live-зелёный ≠ декор; hot ≠ danger)
- [ ] Все числа — JetBrains Mono
- [ ] Скриншот главного экрана выглядит достойно поста в X (скриншотогеничность — фича)

---

## 7. Карта экранов

1. **Dashboard** — 4 стат-карточки (Signals 24h / Hot leads / LLM spend / Top source) → график сигналов 14д (area, amber) + waterfall-теплокарта → список последних hot-сигналов
2. **Feed** — фильтры-чипы → лента signal-карточек → detail-панель (скор, цитата, why, draft, действия)
3. **Leads** — kanban: New → Reviewed → Contacted → Customer; карточки с meter-sm и статусными границами
4. **ICP & Sources** — слева: ICP-текст + positive/negative чипы, список источников с тогглами/расписанием/статусом, LLM-настройки; справа sticky: Test scoring
5. **Stats** — таблица source performance (signals→hot→leads→customers), гистограмма распределения скоров, cost per hot lead, спарк-бары расходов, pipeline value, экспорт

## 8. Реализация

- Стек: React + Vite + Tailwind (токены выше → `tailwind.config` theme), сборка в статику → `embed.FS` в Go-бинарник
- Шрифты: self-host (woff2) — продукт self-hosted, внешних CDN в проде быть не должно
- Иконки: `lucide-react`
- Графики: лёгкие SVG-компоненты свои (как в прототипе) или uPlot; Recharts не тянуть ради 3 графиков
- Тёмная тема единственная в v0.x (`color-scheme: dark`); светлая — только по реальному спросу пользователей
